# Codeforces Random Problem Extension (Chrome)

A Chrome extension that picks a random Codeforces problem based on tags and rating range.

## Features
- Floating dice button on Codeforces pages.
- Filter by tags and min/max rating.
- Unbiased random selection using crypto.getRandomValues.
- Remembers last selections.
- 24-hour cache for fast loading.
- Dark modern UI.

## Installation (Developer Mode)
1. Open `chrome://extensions`.
2. Enable Developer mode.
3. Click "Load unpacked" and select this folder.

## Usage
1. Click the floating dice button on any Codeforces page.
2. Enter tags (comma-separated) and rating range.
3. Click "Pick" to open a random matching problem.
